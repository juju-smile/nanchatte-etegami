# なんちゃって絵手紙

HTML・CSS・JavaScriptだけで動く絵手紙アプリです。外部APIは使いません。

## ファイル

`index.html`、`app.js`、`mobile.js`、`styles.css`、`fonts/`、`images/` を一緒に置いてください。日本語フォントのライセンス文は `fonts/` に入っています。

## パソコンで試す

`index.html` をChromeまたはEdgeで開きます。

## GitHub Pagesで公開する場合

このフォルダーの**中身**をリポジトリの一番上に入れ、GitHub Pagesの公開元をそのリポジトリのルートに設定します。`index.html` が一番上にあることを確認してください。

GitHubへのアップロードや公開設定はまだ行っていません。GitHub Pagesで公開すると、URLを知る人がアプリを開けます。公開する前に、作品画像や説明文に公開したくない情報がないか確認してください。

編集中の作品はブラウザに保存されません。完成したらPNG画像で保存してください。
